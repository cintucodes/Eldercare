# 📋 Pre-Presentation Checklist

## ✅ 24 Hours Before Presentation

### Device Setup
- [ ] Charge presentation device to 100%
- [ ] Clear storage space (at least 2GB free)
- [ ] Disable auto-updates in Play Store
- [ ] Set "Do Not Disturb" mode
- [ ] Increase screen timeout to 10 minutes
- [ ] Set brightness to 100%
- [ ] Disable battery saver mode

### App Installation
- [ ] Install latest ElderCare APK on device
- [ ] Install Health Connect from Play Store
- [ ] Complete Health Connect initial setup
- [ ] Create test elder account (email: elder.demo@test.com)
- [ ] Create test caregiver account (email: caregiver.demo@test.com)
- [ ] Link caregiver to elder account

### Permissions
- [ ] Grant all Health Connect permissions
- [ ] Grant location permissions (for SOS demo)
- [ ] Grant SMS permissions (for SOS demo)
- [ ] Grant phone permissions
- [ ] Verify all permissions in app settings

### Data Preparation
- [ ] Generate test data in Health Connect
- [ ] Sync data to Firestore
- [ ] Verify data appears in Home tab
- [ ] Verify data appears in Health tab charts
- [ ] Add some manual vitals entries
- [ ] Test SOS alert (optional)

---

## ✅ 2 Hours Before Presentation

### Final Testing
- [ ] Open app and verify it loads correctly
- [ ] Test Profile → Generate Test Data button
- [ ] Test Profile → Sync from Health Connect button
- [ ] Navigate through all tabs (Home, Vitals, Health, Profile)
- [ ] Verify charts display correctly
- [ ] Test manual vitals entry
- [ ] Log out and log back in

### Backup Preparation
- [ ] Take screenshots of all key screens:
  - [ ] Profile with Health Connect status
  - [ ] Home tab with synced vitals
  - [ ] Health tab with 7-day chart
  - [ ] Vitals manual entry form
  - [ ] Caregiver dashboard (if showing)
- [ ] Save screenshots to easily accessible folder
- [ ] Create backup elder account with pre-synced data
- [ ] Write down backup account credentials

### Network & Connectivity
- [ ] Connect to reliable WiFi
- [ ] Test internet connection
- [ ] Verify Firestore connection
- [ ] Disable mobile data (to avoid interruptions)
- [ ] Turn off Bluetooth (unless needed)

### Presentation Materials
- [ ] Print DEMO_QUICK_REFERENCE.md
- [ ] Have HEALTH_CONNECT_DEMO_GUIDE.md open on laptop
- [ ] Prepare any slides/PowerPoint
- [ ] Test screen mirroring (if using projector)
- [ ] Have USB cable ready (for screen mirroring backup)

---

- [ ] Check Health tab shows charts

### Mental Preparation
- [ ] Review DEMO_QUICK_REFERENCE.md
- [ ] Practice opening line
- [ ] Practice closing line
- [ ] Review key talking points
- [ ] Prepare for common questions
- [ ] Take a deep breath 😊

## ✅ During Presentation

### Opening (30 seconds)
- [ ] Introduce yourself
- [ ] State app name: "ElderCare"
- [ ] State purpose: "Health monitoring for elders and caregivers"
- [ ] Mention Health Connect integration

### Demo Flow (4 minutes)
- [ ] Profile → Show Health Connect status
- [ ] Profile → Generate Test Data
- [ ] Profile → Sync from Health Connect
- [ ] Home → Show synced vitals
- [ ] Health → Show historical charts
- [ ] Vitals → Show manual entry option

### Closing (30 seconds)
- [ ] Summarize key features
- [ ] Emphasize accessibility (works with/without wearables)
- [ ] Thank audience
- [ ] Open for questions

---

## ✅ Backup Plans

### If Health Connect Fails
- [ ] Switch to manual entry demo
- [ ] Show pre-taken screenshots
- [ ] Explain: "Health Connect is optional enhancement"
- [ ] Focus on manual entry + caregiver monitoring

### If App Crashes
- [ ] Restart app immediately
- [ ] Switch to backup account
- [ ] Continue from where you left off
- [ ] Stay calm and confident

### If Internet Fails
- [ ] Show offline data (Firestore persistence)
- [ ] Explain: "App works offline, syncs when connected"
- [ ] Use screenshots as backup
- [ ] Focus on UI/UX features

### If Device Fails
- [ ] Switch to laptop with emulator (if available)
- [ ] Use screenshots on laptop
- [ ] Walk through features verbally
- [ ] Offer to demo after presentation

## 💡 Pro Tips

1. **Speak slowly** - You know the app better than audience
2. **Make eye contact** - Don't just stare at device
3. **Explain as you tap** - "Now I'm tapping the Sync button..."
4. **Pause for effect** - Let data load, don't rush
5. **Smile** - Confidence is contagious
6. **Handle errors gracefully** - "This is why we have manual entry!"
7. **Time yourself** - Practice with timer
8. **Hydrate** - Have water nearby
9. **Breathe** - You've got this! 💪
